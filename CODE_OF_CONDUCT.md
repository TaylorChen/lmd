# Code of Conduct

## Our Standard

LMD aims to be a small, practical, engineering-focused open source project. Participation should stay respectful, direct, and professional.

Examples of expected behavior:

- discuss technical issues in good faith
- keep critique specific and grounded in behavior or code
- respect different experience levels and backgrounds
- focus on making the project better

Examples of unacceptable behavior:

- harassment, insults, or personal attacks
- bad-faith argumentation or deliberate disruption
- publishing private information without permission
- discriminatory language or exclusionary conduct

## Scope

This applies to project spaces, including issues, pull requests, code review, and other public collaboration around the repository.

## Enforcement

Maintainers may remove comments, close discussions, or restrict participation when behavior damages productive collaboration.

## Reporting

If conduct becomes a problem, contact the maintainers privately when possible. Public escalation should be reserved for situations where private handling is not realistic.

## Notes

This document is intentionally lightweight. If the project grows, it can be replaced with a fuller policy such as the Contributor Covenant.
