# Roadmap

This roadmap reflects the current direction of LMD. It is not a guarantee, but it is the best view of likely next work.

## Near Term

- code signing and notarization for macOS distribution
- stronger PDF output for tables, images, and font handling
- more real file-flow coverage and external change edge-case coverage
- broader workspace search and navigation ergonomics

## Next

- richer Markdown editing helpers
- larger-file search and jump-to-line support
- improved export polish and document styling
- release workflow and version synchronization

## Later

- native Tauri WebDriver automation on supported CI platforms
- broader platform validation outside macOS
- more advanced preview/export parity for complex Markdown documents

## Non-Goals For Now

- cloud sync
- collaborative editing
- note database features
- browser-first deployment
